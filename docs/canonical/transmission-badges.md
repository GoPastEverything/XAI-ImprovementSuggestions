# Transmission badges (TX / RTX / QTX)

iFixedX surfaces X-style post kinds on cards:

| Badge | Meaning |
|-------|---------|
| **TX** | Original post |
| **RTX** | Repost (retweet) |
| **QTX** | Quote post |

Derived from X `referenced_tweets` when using Live API, or seed data offline.

**Repost context line:** optional `repostContext` (who reposted) with main row showing original author.

**Engagement UI:** Reply / RTX / share / views in feed; like/heart primarily in focus modal (product choice).
